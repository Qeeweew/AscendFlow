# 重构前代码保存点

2026-10-14，按用户要求停止算子优化并暂停原开发目标。这是保存当前工作的
checkpoint，不是发布或性能达标声明。后台的四 query 分组编译已终止；外层
`runs/` 的完整和部分产物保留，不纳入产品 Git。

当前代码包括：

- Flash Attention factory、NumPy oracle 和 CANN 对照适配器移到 `examples/`。
  其他算子 factory/oracle 仍在编译器包内，需在重构中统一迁出。
- 通用逻辑 epoch、native segment、周期激活区间、多端点 GM 交接，以及局部
  有符号 generation 距离。最终检查仍从真实物理访问和同步位置重新计算。
- 分层 Attention 示例的逻辑 BK 与 Cube/Vector 物理块分别表达；目前使用的
  `cube.task`/`vector.task` 仍是低层原生构造，不作为新的公共 DSL 设计定案。
- Row broadcast 的两种合法 repeat 组织及对应原生调用计数。

验证状态：

- Ruff、格式检查和 `git diff --check` 通过。
- 此前完整回归 299 项通过；之后新增的分层回归 9 项和物理扩展回归 21 项
  分别通过。两者不能作为当前保存点完整回归通过的声明。
- 连续两 query 小例已验证全部 32,768 个输出，最大绝对误差 3.0518e-5。
  该设备产物采用一次完整 QK 块的提前量。
- 4K 测试中，分层初版为 1143.354 µs；一次完整 QK 块的提前量配合 V 预取和
  行广播变化后为 1260.196 µs。此结果是回退，不是优化成功。历史 BK128
  版本为 1034.870 µs，安装 CANN 对照为 513.828 µs，均为独立 profiler trial。
- 最后恢复两块 QK 提前量的版本完成 4K CANN 离线编译，但未完成新设备正确性、
  性能和完整回归。不得将之前的设备结果归于这个最新排步。

下一步范围是 DSL、Python 编译耗时和编译器/算子目录边界的重构；暂停新的
算子性能搜索。后续优化必须同时保留生成 ASC、对应 AscendC 实现、设备 profiler
和硬件模型证据，不能仅用源码布局或活动比例宣称缩小性能差距。
