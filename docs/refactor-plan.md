# 大幅重构实施计划

2026-10-16。此计划替代此前围绕 child/parent/query 传播优化的执行路线。**M0完成，M1基础和M2局部闭环已落地，用户已在`959f79e`之后恢复重构；完整主线仍未替换。各阶段实际结果见状态页。** 不继续停止的 origin 缓存、虚拟节点和堆调度实验；不恢复算子调优。

目标设计见[结构化循环](design.md)，目录与依赖见[源码结构](source-layout.md)，保持合同见[不变量](compilation-invariants.md)。实际进展只能写到[状态页](refactor-progress.md)，本页不堆历史测试日志。

## 1. 必须同时解决的问题

| 问题 | 此次要改变的结构 |
|---|---|
| 外层 Q 循环专用处理 | 普通 sequence/loop/pipeline 的同一递归组合；删除 QueryChannel/QuerySync 及 query 分析器 |
| child/parent/query 全来源条件传播 | 真实访问依赖 + 有类型的完成前沿 + 循环回边合同；不把全闭包藏进 summary/covers |
| 循环被固定层级限制 | 统一 PLE，允许普通前置/后置工作与嵌套循环；runtime 与常量界一致 |
| 平铺模块、反向依赖和大文件 | 按 IR、目标合同、分析、变换、后端、运行工具分层；移动同时消除职责耦合 |
| frontend/lowering 重解释同一信息 | 一次构建结构与类型；固定政策/地址/原语effects 在明确阶段建立 |
| 前端接受、后端拒绝且报错失焦 | 统一admission能力表；非法/不支持/资源不足/预算未决分别诊断并保留源位置 |
| 一个原语在多处独立维护合同 | 唯一明确的数值、footprint、完成与native表示合同，前端/lowering/emitter各守职责 |
| 标量化简藏在 ASC emitter | 显式纯标量 pass；event ID 表达式与地址正常化，输出只打印 |
| 事实所有权与验证职责不清 | 保留有用的 normal/deep 分离，去掉阶段间重复求证和外部信任标记 |
| 测试绑定旧图状态、全量回归过重 | 按硬件/语义合同迁移，独立模型分级，结构成本测试先于冷计时 |
| 文档与证据混杂 | 单一当前状态、计划、设计；历史原文与运行数据在产品仓库外 |
| 支持、编译、设备资格混淆 | 真实 DSL→ASC→CANN→设备分别登记；变体不沿用旧实现证据 |

## 2. 实施顺序与退出门槛

### M0：记录现场与文档收敛（已完成）

- 实际产品 HEAD `7ddaa54ec060a92e219d0462df162939b8b32d72`；保留全部未提交源码/测试实验。
- 历史文档原文、SHA256、Git状态与本轮代码未变清单存入外层 `reports/compiler-refactor/20261016-before-structured-loops/`。
- 产品文档保留当前合同和最少必要的用户参考；清除旧计划的权威性，更新 README 和链接。
- M0仅文档整理，不运行编译、CANN、设备或全套测试，不将文档完成写成编译器完成。

退出：新计划明确循环算法、目录依赖、旧路径删除、成本及性能门槛；代码现场未变。

### M1：统一控制语义和包边界

先落实最小底层类型与目标原语合同，建立 source/physical dialect 边界；把循环构造从特定 scope/query lowering 中抽出。新代码直接落入目标包，每迁移一项同时修改导入与对应测试，禁止先把全部旧代码复制到新目录。

具体产出：

1. 一份 sequence/loop/pipeline 的递归遍历与 coordinate binding；actor 域不再选择独立控制算法。
2. PLE 转换保留 runtime N；长、短、零次不重不漏，普通前后操作可组合。
3. 稳定且有类型的 entry/exit/carry 端口，指向真实插入 cut；控制退出不等同退休。
4. 交付带入口前提的参数化状态变换：归一条款形状、比较/合流与幂等规则、循环归纳和有限新增界。固定政策下的状态界必须由控制/effects/依赖推出，与N、重复查询数和历史origin数无关；小反例用于找错，不能替代闭合与复杂度论证。
5. 统一输入诊断类别和源码位置传递；对scalar carry、runtime child、受限guard列明admission，不以“必须是KV/query”掩盖缺失能力。

验收：双缓冲、循环后覆写、嵌套空/短循环、两个相邻循环、loop 前后各有 native、子循环 early release。比较执行实例/地址/词法次序，不调用旧完成图来定义期望结果。固定/符号 N 共用转换，不新增展开捷径。

停止条件：若首个双缓冲或嵌套例仍需要复制完整子图、逐迭代枚举或一般全来源闭包，则回到算法设计，不继续堆更复杂算子。

### M2：访问、完成前沿与局部同步生成

- native lowering 一次交付精确 effects；按 root/range 建立 reaching definition 和 RAW/WAR/WAW，保留 strided holes、重叠view、scratch、owner、slot。
- 原语合同明确数值和实际native表示；Load2D等recipe的内部指令/读写必须在分析前可见，不能留到emitter才暴露。保留原始轴合法性与host整数溢出检查。
- 将现有标量/布局纯工具迁到明确的职责层；只复用语义正确的代码，不迁移旧 query 查询适配器。
- 固定排步下由前沿覆盖省略冗余同步，对缺口构造 typed capture/acquire；归纳覆盖 loop backedge。
- 从双缓冲扩展到 Cube/Fixpipe 和带 Scalar reader 的 reduction，同一 pass 使用不同目标合同。

验收：有前后 IR、同步序列、最后 reader 反例及等待范围解释。无新增搬运/槽位/全局barrier；S/M/V/MTE/FIX 反例仍成立。成本随模板、真实相交和边界增长，与 N 无关。

### M3：嵌套组合、CV 与统一事件资源

- 同一边界组合处理 serial 输出块、KV流水、native child；移除“serial 内必须只有一个 KV pipeline”的结构限制。
- AIC:AIV=1:2保留单Mixed控制树与一份参数化AIV代码，sid是runtime坐标；分析按实际participant区分私有UB、访问和quorum，禁止为身份区分复制AIV body。
- CV FIX→GM→AIV ready、双AIV release、反向 credit、控制器 Wait 的进展接入目标合同。
- 逻辑 lease 在同一资源分配入口处理，不再先 child 再 parent 再 query 分别重新求证。入口内部可按不相交 bank/约束分量分解。
- 保留既有 event borrowing、FIRST/LAST、跨片段未消费状态和最终收尾。不足时精确诊断；不加全循环等待回避资源问题。

验收：同构的嵌套 GEMM、状态 recurrence、FA 输出块循环走同一语义；改变量名、循环标签或 example 名不影响选择。默认 FA 原算法/政策通过新路径，不在编译器出现 attention/query 特判。有限模型检查小规模实际 Set/Wait/ID；独立检查单列。

### M4：贯通公共入口并删除旧路径

- `compile` 只有一条 source→physical→PLE/同步/资源→ASC 主线；外部同步 IR 的独立验证是输入方式区别，不是算子后端。
- 删除已被替代的 query、scope/sequence/invocation 专用完成求解和 Channel/Sync 类；保留的原语合同搬到目标层。
- 旧通用闭包只允许作为小规模显式 debug/reference，若无独立价值则删除；生产调用不能静默回退。
- 原有模型对象拆成 IR提取、访问分析、完成语义、输出数据；emitter 不导入同步规划器，不在输出时重新决定协议。
- canonicalize/CSE 用于已确认纯的标量 IR；event width=1 输出常量，连续映射化简按整数等价合同。无需为此重证同步。

验收：代码依赖单向；没有仅用于兼容旧内部模块的转发层；旧 task DSL 仍不存在。当前 examples 通过真实公共入口，FA 不由手写 ASC 替代。若过渡期有实验入口，必须显式选择且标注未完成；最终删除，不保留两套正常后端。

### M5：工作量、编译耗时与生成代码验收

先做结构成本测试，再做一次 FA 单次 probe。接近门槛后才运行五个独立冷进程，不在每个小补丁后重复整算子。

| 项目 | 门槛 |
|---|---|
| 默认 FA source→ASC | 五次 p50≤5s、max≤10s；源码和既有 BQ128/BK1024/CK128/VR8 政策不变 |
| 小算子 | GEMM、scale、softmax、RMSNorm 不显著回退；同时报告绝对时间和与冻结基线差异 |
| 输入长度 | runtime Sq/Sk 共用产物；合法固定 N=2^10/2^20 的分析结构不按 N 展开 |
| 结构增长 | 模板32/64/128、slot2/3/4、嵌套1/2/4的受控输入，按M1给出的状态与更新上界加入量化断言；超过即失败 |
| 总预算 | 每个 build 从构造到 CANN≤300s；超时/失败终止整个所属进程组并停止下一候选 |
| 输出与执行组织 | 无额外copy/buffer/barrier；early release、CV重叠和事件共享保持 |

源码→ASC包括文件构造、前端、全部分析、化简、生成与产物快照；另列 import、完整进程、CANN、RSS。不得挪走成本或跨编译cache美化结果。阶段数据和源码/编译器/ASC身份存外层 runs。

至少三个成本断言必须先落地：(1) 固定政策、相同合法余数类的大N变化，不增加模板、边界键和条件分区数；(2) 同一已建立合同读取1次或100次，状态和建立次数不变，只允许读取成本增长；(3) k个互不耦合的约束分量，状态数不得超过各分量状态之和加线性索引，不能产生分量间的来源×节点乘积。相连模板族另以实际I/H/B/C/J及固定P/G的推导上界验收；如果M1给不出该界，M5不能用“增长可解释”放行。真实相交或资源冲突本身平方增长的输入必须单列，不能将算法额外平方归因给它们。

新 PLE 可能改变等价循环、变量名和 event 编号，因此不能一概要求 ASC 字节相同。固定源码首先做 native/地址/控制/同步组织对照；只有纯表示改动且输出未变时，哈希相同可作为强证据。有限差分不是任意 N 证明。

### M6：离线与设备资格，随后才恢复算子性能工作

新路径通过相关 CPU 回归与独立检查后，做 CANN 离线构建。生成变化需要设备验证，先检查所有卡并显式映射；不reset、不换卡绕过错误。M1底层迁移不提前启动设备调优。

编译重构不能以牺牲核执行性能达标。FA 用4K/8K主例，区分全输出与采样检查；对比固定政策手写AscendC、安装版ACLNN和ops-transformer源码，结合msprof设备task、pipe activity、访存及依赖停顿。理论下界使用实际硬件参数及FLOP/字节数，未核实带宽单位不能作为结论。

新编译器资格完成后，才安排 dtype/MHA/GQA/MQA/causal/tail/varlen/paged/sparse/persistent 等 attention 变体及其他算子。每项扩展以通用控制、访问或原语合同接入；不为算子名增加编译器分支，不在本次重构中顺带改算法或调参。

语言复用随后按真实需要补透明AST宏：静态作用域/类型、source位置、scratch/effects与普通循环必须保留。当前函数调用限制如实列出，不靠opaque回调或编译器内置整算子解决examples代码重复。

每个阶段的小补丁同时给出：新入口、替代的旧职责、尚未删除原因、针对性命令、结果及未解决问题。M1–M3按本阶段合同和显式新入口验收，并登记仍保留的旧生产调用；只有M4公共路径切换且被替代路径退出，才能标记全产品迁移完成。包结构迁移数量和测试总数不是验收标准。
